Span
audio bridges

Introduction

Span is an audio-first, blind-accessible take on Hashiwokakero — the "Bridges" logic puzzle. Islands sit on a grid, each showing a number. You build bridges between them — straight, horizontal or vertical, one or two between any pair — so that every island carries exactly its number of bridges, no two bridges cross, and all the islands join into a single connected network.

It is a pure logic puzzle: every board is generated from a real bridge network, so a valid solution always exists. You have a generous move budget per board; run it dry and the puzzle is failed, costing one of three lives. Solve a board to climb to a larger one.

Span reads by ear, and the listener never turns: north is always in front of you, south behind, east to your right, west to your left. Because bridges run in those four directions, the compass scan and every bridge you build sound from their true bearing. The cursor hops island to island; each island's tone pans to its column and rises in pitch toward the top of the board.

System Requirements

This is best experienced with headphones and a gamepad.

Real-time synthesis is an extremely CPU-intensive process. It will attempt to run on any machine that meets its minimum requirements; however, you may experience stuttering or drop-outs when running below the recommended requirements.

Minimum System Requirements

CPU SSE2 capable (64-bit)
RAM 2 GB

Recommended System Requirements

CPU 3.5 GHz Quad-Core (64-bit)
RAM 4 GB

Browser Support

The HTML5 build is intended to be played in a recent version of a Chromium-based browser, such as Google Chrome, Microsoft Edge, or Opera. Browser extensions that alter page behavior are not recommended. Other browsers must support modern JavaScript features and the current Web Audio API specification.

How to Play

The cursor sits on an island. Press an arrow to hop to the next island in that direction; you'll hear its position and be told its number and how many bridges it currently carries. Press Space to scan the compass from where you are — each of the four directions plays a cue: near-silence for open water, a soft pip for a reachable island with no bridge yet, and a taut tone (doubled for two bridges) where a bridge already runs.

To build, select the island with Enter, then press a direction: the first press lays one bridge that way, a second makes it a double, a third removes it. As a shortcut, hold Shift and press a direction to do the same in one step without selecting. A bridge that would cross another is refused with a buzz. When you land on an island that already carries exactly its number, you hear a soft shimmer.

Press C to describe the current island and what lies in each direction; F2 lists the islands that don't yet carry their number — the audio equivalent of scanning the board.

Connect every island into one network with the right number of bridges on each to solve the puzzle and climb a level; the fewer moves you spend, the more you score. Run out of moves and the puzzle is failed, costing a life. Out of lives ends the run — enter your name to save your score.
